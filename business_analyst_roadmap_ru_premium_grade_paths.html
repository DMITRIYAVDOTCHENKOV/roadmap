🌱 Junior BA: путь изучения на 12–16 недель

Цель: уверенно проходить стажерские и junior-собеседования, делать базовую документацию, читать API и писать SQL-запросы.

стартРФ45 шагов

1. Роль BA/SA и SDLC

Понять, где аналитик находится в команде и как требование проходит путь от идеи до релиза.

  • BA vs SA vs Product
  • Agile, Scrum, Kanban
  • Жизненный цикл требований
Atlassian AgileКто такой BA

2. Сбор требований

Интервью, воркшопы, анкеты, анализ документов и фиксация договоренностей.

  • Stakeholder map
  • Interview guide
  • Problem statement
Сбор требованийIIBA Elicitation

3. User Stories и Acceptance Criteria

Научиться описывать ценность, сценарии и проверяемые критерии приемки.

  • As a / I want / So that
  • Given / When / Then
  • Definition of Done
User StoriesAcceptance Criteria

4. BPMN 2.0

Моделировать AS-IS/TO-BE процессы, находить узкие места и согласовывать изменения с бизнесом.

  • События, задачи, шлюзы
  • Пулы и дорожки
  • Ошибки в схемах
BPMN specОсновы BPMN

5. SQL база

Читать данные, проверять гипотезы, делать выгрузки для анализа и тестирования требований.

  • SELECT, WHERE, JOIN
  • GROUP BY, HAVING
  • CTE basics
Stepik SQLPostgreSQL SQL

6. API basics

Понимать HTTP, REST, JSON, коды ошибок и читать OpenAPI/Swagger спецификации.

  • GET/POST/PUT/PATCH/DELETE
  • 200/400/401/404/500
  • Request/response
MDN HTTPOpenAPI

7. Документация

Собрать первый пакет артефактов: BRD/SRS-lite, User Story Map, RTM и UAT checklist.

  • BRD/SRS структура
  • Traceability
  • UAT сценарии
Шаблоны в документеПримеры портфолио

8. Junior portfolio

Сделать 2 кейса: HelpDesk и интернет-магазин. Это даст материал для резюме и собеседований.

  • BPMN + User Stories
  • SQL tables
  • API contract example
Pet-проектыGitHub пример
Как учиться: сначала роли и требования, затем BPMN, SQL и API. После каждого модуля делайте артефакт в портфолио — так знания сразу превращаются в доказательство навыка.

🌾 Middle BA: путь изучения на 4–6 месяцев

Цель: вести фичи end-to-end, проектировать интеграции, управлять стейкхолдерами и принимать решения на данных.

45 шаговhybrid BA/SA

1. Интеграции

REST/SOAP, OpenAPI, ошибки, идемпотентность, версии API, интеграционные сценарии.

  • Sequence diagram
  • Contract-first подход
  • Error handling
OpenAPIHTTP статусы

2. Асинхронность

Очереди, события, Kafka/RabbitMQ, delivery semantics и eventual consistency.

  • Topics/queues
  • Consumer groups
  • Retry/DLQ
Kafka docsRabbitMQ tutorials

3. Product/Data skills

Метрики продукта, воронки, retention, cohort analysis, A/B testing, unit economics.

  • KPI/OKR
  • North Star Metric
  • Гипотезы
North StarA/B testing

4. BI и данные

SQL advanced, витрины, дашборды, качество данных, источники и lineage.

  • Window functions
  • DWH basics
  • BI dashboards
SQL практикаPower BI docs

5. Фасилитация

Проводить workshops, conflict resolution, приоритизацию и согласование решений.

  • Workshop agenda
  • Decision log
  • MoSCoW/RICE
MoSCoWRICE

6. Middle portfolio

Сделать кейс CRM или интеграционной платформы: API, sequence, BPMN, метрики, SQL.

  • CRM funnel
  • Telephony integration
  • BI dashboard
Pet-проектыШаблоны
Фокус Middle: не просто описывать требования, а снижать неопределенность, связывать бизнес, разработку, тестирование и данные.

🌳 Senior BA: путь изучения на 6–9 месяцев

Цель: вести сложные enterprise-направления, влиять на архитектуру, доменную модель и качество аналитики.

35 шаговenterprise

1. Solution & System Design

C4, ADR, trade-offs, архитектурные ограничения, NFR и high-level design.

  • Context/Container/Component
  • ADR
  • NFR quality attributes
C4 ModelADR

2. Domain-Driven Design

Bounded contexts, ubiquitous language, aggregates, domain events и Event Storming.

  • Domain map
  • Context map
  • Event Storming
Bounded ContextEvent Storming

3. Enterprise integration

ESB, Kafka, BPM engines, MDM, DWH, orchestration/choreography.

  • Integration patterns
  • Data contracts
  • Process automation
EIPCamunda docs

4. Security & Compliance

OWASP, персональные данные, роли/права, аудит, логирование и risk analysis.

  • Access model
  • Audit trail
  • Threat modeling basics
OWASP Top 10152-ФЗ

5. Наставничество и ревью

Ревью требований, стандарты документов, онбординг аналитиков и качество артефактов.

  • Checklist review
  • Definition of Ready
  • BA guild
ШаблоныИнтервью вопросы

6. Senior portfolio

Кейс платежной системы/банка: статусы, события, идемпотентность, риски, мониторинг.

  • Architecture diagrams
  • API contracts
  • NFR + risks
Pet-проектыПортфолио
Фокус Senior: ответственность за решение целиком — от бизнес-цели и рисков до архитектурных ограничений и внедрения.

⭐ Lead BA: путь развития практики

Цель: строить BA-функцию, управлять стандартами, наймом, качеством аналитики и стратегическими инициативами.

25 шаговleadership

1. BA Practice Management

Стандарты, шаблоны, governance, maturity model, контроль качества аналитики.

  • BA playbook
  • Quality gates
  • Templates library
BABOKШаблоны

2. Strategy & Portfolio

Связь целей компании, product roadmap, OKR, инициатив и бизнес-ценности.

  • Strategic alignment
  • Portfolio prioritization
  • Outcome metrics
OKR basicsProduct Roadmap

3. People Leadership

Найм, интервью, матрица компетенций, индивидуальные планы развития, менторство.

  • Competency matrix
  • Interview scorecard
  • Career ladder
Вопросы интервьюКарьерные треки

4. Enterprise Architecture

Бизнес-архитектура, capabilities, value streams, доменная карта и IT-landscape.

  • Capability map
  • Value streams
  • Target architecture
TOGAFC4 Model

5. Change Management

Управление изменениями, коммуникационный план, сопротивление, обучение пользователей.

  • Stakeholder engagement
  • Adoption metrics
  • Training plan
ADKARШаблоны

6. Lead portfolio

Показать не один кейс, а систему: стандарты, команда, метрики качества, transformation roadmap.

  • BA playbook
  • Governance model
  • Team KPIs
ПортфолиоКарьера
Фокус Lead: не выполнять аналитику руками, а создавать условия, в которых вся аналитика в компании становится предсказуемой и качественной.

Checklist портфолио

  • 5 кейсов: CRM, e-commerce, банк, ERP, helpdesk
  • AS-IS / TO-BE BPMN
  • User Stories + Acceptance Criteria
  • Use Case / Sequence / ERD
  • API контракт: endpoint, request, response, errors
  • SQL-запросы и BI-дашборд
  • BRD/SRS/RTM/UAT artifacts
  • Результат: эффект, метрики, выводы

Pet-проекты для портфолио

Junior: HelpDesk

Заявки, статусы, роли, SLA, BPMN, User Stories, SQL-таблицы.

Junior: Интернет-магазин

Каталог, корзина, оплата, доставка, возвраты, CJM, API.

Middle: CRM

Лиды, сделки, воронка, интеграция с телефонией и BI.

Senior: Платёжная система

Anti-fraud, очереди, статусы платежей, идемпотентность, мониторинг.
